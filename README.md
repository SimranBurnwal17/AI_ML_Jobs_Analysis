# AI & ML Jobs Analysis | Power BI Dashboard

## Project Overview

This project focuses on analyzing the AI and Machine Learning job market using Power BI. The dashboard explores job opportunities, salary distributions, experience levels, geographical trends, company insights, and in-demand technical skills.

The objective is to transform job market data into meaningful insights that help understand hiring trends and salary patterns across different AI and ML roles.

## Project Objectives

- Analyze the distribution of AI and ML job opportunities.
- Understand salary trends across different experience levels.
- Identify countries and cities with job opportunities.
- Explore company-wise hiring patterns and job roles.
- Analyze the demand for technical skills.
- Examine the relationship between remote work opportunities and salaries.

## Tools & Technologies

- Power BI – Data visualization and interactive dashboard development.
- Power Query – Data transformation and preparation.
- DAX – Measures and calculated metrics.
- Microsoft Excel / CSV – Dataset handling (if applicable).

## Key Business Questions

1. Which experience level has the highest number of job opportunities?
2. How do salaries vary across different experience levels?
3. Which countries and cities have the highest number of job postings?
4. Which companies offer opportunities across different AI/ML roles?
5. Which technical skills are most commonly represented in the dataset?
6. How does remote work availability vary across job roles?
